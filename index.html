Concept 1: Hosted LLM APIs vs. Self-Hosted Open-Source Models

Status: 🟢 Understand the concept

What is it?

Choosing between renting an AI brain via external API (OpenAI/Gemini) vs. hosting a free, public model blueprint (Llama) on our own cloud infrastructure.

Why care as a DM?

APIs offer rapid time-to-market but carry variable Opex costs and external data privacy risks. Open-Source requires high upfront Capex and cloud expertise but guarantees data security and predictable infrastructure pricing.

Concept 2: Version-Controlled Documentation (Docs-as-Code)

Status: 🟡 Know how to configure or use it

What is it?

Writing technical and delivery documentation in lightweight formats (like Markdown/HTML) and managing it inside a Git repository alongside the codebase, utilizing automation to publish it live.

Concept 5: The 3-Tier Enterprise AI Architecture

Status: 🟢 Understand the concept

What is it?

A structural classification framework inside a Microsoft/Azure corporate environment that categorizes AI solutions into three tiers based on process complexity, data scale, and deployment governance[cite: 2, 3].

  • Tier A (Agent Builder): Fast, built-in, low-friction bots running out of the box in M365 Copilot, using localized text files on SharePoint[cite: 1, 3].
  • Tier B (Copilot Studio): Fully managed workflow applications using Power Automate, proactive alerts, multi-step routing, and strict environment deployment pipes (ALM)[cite: 2, 3].
  • Tier C (Azure AI Foundry): High-capacity data services leveraging Azure OpenAI, AI Search, and Document Intelligence (OCR) to ingest heavy datasets or complex layouts[cite: 2, 3].

Why care as a DM?

It directly governs how you open roles and triage features[cite: 2]. Tier A requires low effort, Tier B requires specific Power Platform/ALM engineering capabilities[cite: 2, 3], and Tier C demands data engineers and larger consumption budgets[cite: 1, 2]. Skipping this filter causes major delays when low-tier systems fail to handle high-tier data loads[cite: 1, 3].

Questions to Ask during Use-Case Triage

  • "Of the 18 remaining PayUK use cases, how many pass the Tier C filter (requiring deep table parsing or documents over 300 pages) versus basic text search?"[cite: 3]
  • "Have we requested the Copilot Studio development environments from the client's tenant administrators, or are we gated by platform governance approvals?"[cite: 2, 5]

Simple Analogy

Tier A (Agent Builder) = A breakroom bulletin board: Free, immediate, great for pinning up reference documents, but it cannot actively route packages or notify people[cite: 1, 5].
Tier B (Copilot Studio) = An automated mail room: Actively sorts packages, tracks delivery signatures, and dynamically sends reminders[cite: 2, 3].
Tier C (Azure AI Foundry) = An industrial shipping hub: Uses forklifts, processes complex custom cargo manifests, and handles massive commercial freight[cite: 2, 3].
